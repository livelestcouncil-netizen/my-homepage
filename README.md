# リベレスト社会保険労務士事務所 ホームページ

リベレスト社会保険労務士事務所の公開ホームページを管理するリポジトリです。HTML・CSSと画像、PDF、動画などで構成し、GitHub Pagesで公開しています。

- 本サイト：https://livelestcouncil-netizen.github.io/my-homepage/
- リポジトリ：https://github.com/livelestcouncil-netizen/my-homepage

## 更新の基本手順

1. 最新の `main` を確認してから作業を始めます。
2. ローカルのテストサイトで変更し、表示・文章・リンクを確認します。
3. 馬場さんに確認用URLと変更内容を案内します。
4. 本サイトへの反映について承認を得た後、確認済みの変更だけを `main` に反映します。
5. GitHub Pagesの公開処理が成功したことを確認し、本サイトの確認用URLを案内します。

テストサイトには最上段に赤い案内帯を表示します。本サイトへテスト用の帯や設定を持ち込まないでください。今回の作業と無関係なローカル変更は、まとめて公開しないでください。

ローカル確認に使用しているURLは `http://127.0.0.1:8765/` です。このURLはテスト用サーバーが稼働しているPCで使用します。起動方法は作業環境側で確認してください。

## コラムを追加・更新するとき

- 既存記事のデザイン、見出しの階層、パンくず、日付表記にそろえます。
- `columns.html` とトップページの「最新のコラム」を更新します。
- タイトル、meta description、canonical、OGP、構造化データを本文と一致させます。
- 新規URLを `sitemap.xml` と `sitemap.txt` に追加します。重複URLやテスト用URLは入れません。
- 公開日と更新日は区別します。`lastmod` は実際に内容を変更した日を記載し、日付だけを一律に更新しません。
- 社会保険労務士が確認済みの本文は、法令説明・数値・日付を無断で変更しません。疑問点や誤字は確認を求めます。
- 法令や制度の説明を新たに加える場合は、公的な一次資料で確認し、出典と情報の基準日を示します。

## リベレスト通信

作成済みの通信を利用し、対応するコラムの記事内にダウンロード案内を置きます。1枚目の縮小画像からPDFを開く・ダウンロードする形を基本とします。資料の内容・日付・リンク先と、スマートフォンでの表示を確認してください。

## 表記・内容の方針

- 資格名は **自立型人財・組織育成士** と記載します。「人財」と「組織」の間の中黒を省略しません。
- 「自立型人財の育成」など、資格名ではない文章を一括置換しないでください。
- **障害者職業生活相談員** の表記を使用します。
- 大阪府を中心とした対応方針を保ち、茨木市だけに対象を限定するような表現は避けます。
- 訪問・オンライン・メールで対応します。遠方への訪問では別途交通費が発生する場合があります。
- 電話の受付時間は9時〜18時。問い合わせフォームには原則3日以内に回答する案内を使用します。営業日は指定しません。
- 支援事例は確認済みの事実に基づき、成果の数値や企業情報を推測で追加しません。

## キャラクター・画像・動画

リーベちゃん、ヨツバくん、ひだまりちゃんは、最新の公式設定と承認済み素材を使用します。作業環境に `liebe-character` スキルがある場合は、設定・口調・素材の扱いを確認してください。

キャラクターの見た目や性格を無断で変更せず、資格・法令の説明の正確さを優先します。動く画像には静止画への切り替えを用意し、音声付き動画は自動再生しません。音声などの利用条件とクレジットも維持します。

## 公開前の確認

- パソコンとスマートフォンで文字や画像がはみ出していないか
- ページ内リンク、関連サービス、問い合わせ、PDFのリンク先が正しいか
- 見出しと公開日、本文、検索向け設定が一致しているか
- canonicalが本サイトの正しいURLになっているか
- 意図せず `noindex` が付いていないか
- 構造化データのJSONが正しく、ページ内容と一致しているか
- サイトマップのURLと更新日が正しいか
- テスト用の帯・URL・非公開情報を公開していないか

GitHub Pagesのプロジェクトサイトでは、`robots.txt` がこのリポジトリにあることだけで、ドメイン直下のrobots設定として有効とは判断しません。

## 検索の状況確認

Google Search Consoleでは、クリック数・表示回数・検索語・ページ別の状況と、URL検査・サイトマップの取得状況を確認します。集計の更新日と対象期間も記録してください。

「登録リクエスト受付」「登録可能」「インデックス登録済み」は異なります。送信の成功だけで登録完了や順位向上と判断しません。データが少ない段階では、平均順位やクリック率だけで成果を断定しないでください。Bingの登録状況はBing Webmaster Toolsで別途確認します。
